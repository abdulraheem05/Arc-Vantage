Arc Vantage is a full-stack e-commerce website designed to deliver a smooth online shopping experience through intuitive product discovery, customer accounts, and streamlined order management.

## ✨ Key Features

### 🛍️ Product Discovery

- Browse a curated collection of home and kitchen essentials.
- View product images, descriptions, materials, categories, and prices.
- Filter by category, material, and price range.
- Sort products based on preferences.

### 🔐 Authentication & User Accounts

- Google and email/password authentication.
- Individual customer accounts.
- Personal profile and delivery information management.
- Profile completion during onboarding.

### 🛒 Shopping & Checkout

- Seamless product browsing and checkout experience.
- Delivery information collection.
- Order placement and itemized order details.

### 📦 Order Management

- View customer orders and associated items.
- Store order quantities, prices, and totals.
- Access digital invoices or receipts.

### ❤️ Wishlist & Reviews

- Save favourite products for later.
- Support customer reviews and product feedback.


## 🧰 Technology Stack

| Technology | Purpose |
| --- | --- |
| Next.js | Full-stack application and routing |
| React | User interface |
| JavaScript | Application logic |
| Tailwind CSS | Styling and responsive design |
| PostgreSQL | Relational database |
| Supabase | Hosted database infrastructure |
| NextAuth.js | Authentication management |
| Google OAuth | Google sign-in |
| Vercel | Application deployment |

## ⚙️ Platform Highlights

- **Full-stack architecture:** Integrates frontend, backend, and database functionality.
- **Relational data management:** Organizes products, users, orders, and order items.
- **Cloud infrastructure:** Uses Supabase and Vercel for database hosting and deployment.
- **Secure authentication:** Integrates customer sign-in with account data.
- **Modular codebase:** Separates application routes, data access, and user-facing pages.
